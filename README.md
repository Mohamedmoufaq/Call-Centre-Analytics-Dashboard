# 📞 Automated Call Centre Analytics Dashboard

An interactive and automated Excel analytics dashboard designed to analyze call centre operations, monitor key performance indicators (KPIs), and derive actionable insights regarding call volumes, agent efficiency, and customer satisfaction.

## 🎯 Business Problem & Purpose

Call centre managers often struggle to track operational performance across multiple metrics—such as call volume, average handle time, abandonment rates, and customer satisfaction ratings—using raw, unstructured log data. 

This project automates data aggregation and visual analysis to help operational leadership:
- Monitor daily and monthly call traffic patterns.
- Evaluate individual agent performance and resolution efficiency.
- Identify service bottlenecks to optimize workforce scheduling.

---

## Key Features & Highlights

- **Dynamic Slicers & Filters:** Interactive filtering by channel, department, call duration, and agent.
- **KPI Metrics Cards:** Instant visibility into Total Calls, Average Customer Satisfaction Rating, and Call Handling Rates.
- **Pivot Charts & Visualizations:** Clean breakdown of call distribution across time intervals and categories.
- **Data Modeling & Cleaning:** Formatted raw call logs into clean structured tables using Excel data tools.

---

## 🛠️ Tools & Technologies Used

- **Microsoft Excel** (Advanced Pivot Tables, Pivot Charts, Dynamic Slicers)
- **Power Pivot & Data Modeling**
- **Data Visualization & KPI Dashboarding**

---

## 🚀 How to View & Use

1. Clone or download the repository to your local machine.
2. Open the `.xlsx` file using **Microsoft Excel (2016 or newer)**.
3. Use the **Slicers** on the dashboard tab to interactively filter metrics across agents, dates, and call types.
